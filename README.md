# Weather Data Visualization with Matplotlib

## 📌 Objective:
This project demonstrates how to use Matplotlib to visualize weather data like temperature, humidity, and rainfall through various types of plots.

## 📂 Files:
- `weather_data.csv`: Sample weather data for one week.
- `main.py`: Python script to read data and generate visualizations.
- `README.md`: Project overview and documentation.

## 📊 Visualizations:
- Line Plot for Temperature
- Bar Chart for Humidity
- Scatter Plot for Rainfall vs Temperature
- Pie Chart for Rainfall Distribution

## 💻 Requirements:
- Python 3.x
- pandas
- matplotlib

## 📦 How to Run:
```bash
pip install pandas matplotlib
python main.py
